## 1. 사전 준비 (픽스처)

- [ ] 변경 파일이 20개 이상(스크롤이 생길 만큼) 있고, 그중 일부는 stage 된 저장소를 연다
- [ ] `git stash push` 를 2회 실행해 스태시 2건을 만든다
- [ ] 커밋이 5개 이상 있어 Graph 섹션이 렌더되는 상태로 둔다

## 2. 배치·가시성

- [ ] 섹션 순서가 위에서부터 **Merge Changes → Staged Changes → Changes → Stashes → Graph** 인가
- [ ] **스태시를 전부 drop 한 뒤**(0건) 파일을 수정했을 때, "스태시" 섹션이 **아예 보이지 않는가**
      (이전 동작: 변경만 있어도 빈 스태시 헤더가 목록 맨 위에 떴다 — 이번 수정의 핵심)
- [ ] 파일 수정 → 되돌리기를 반복할 때 목록 최상단에 섹션이 나타났다 사라지는 **점프가 없는가**
- [ ] 워킹트리를 완전히 깨끗하게 만들면 변경 그룹 3종이 모두 사라지고 **"변경사항 없음"** 한 줄만 남는가
      (스태시·커밋이 있으면 그 두 섹션은 그대로 보여야 한다)
- [ ] 충돌을 만들면(merge conflict) `Merge Changes` 섹션이 맨 위에 나타나는가
- [ ] 커밋이 0건인 새 저장소에서 Graph 섹션이 렌더되지 않는가

## 3. Stash 버튼 이동

- [ ] 상단 헤더 바(브랜치 오른쪽, Sync 왼쪽)에 **Archive 아이콘 Stash 버튼**이 있는가
- [ ] 변경이 0건이면 그 버튼이 **비활성(흐림)** 이고, 툴팁은 그대로 뜨는가
- [ ] 변경이 있을 때 클릭하면 스태시가 생성되고 성공 토스트가 뜨는가
- [ ] remote 가 없는 저장소에서도 Stash 버튼이 우측 정렬로 자리를 잡는가(Sync 버튼은 미표시)

## 4. 접이식 헤더 (chevron · sticky)

- [ ] 각 섹션 헤더 왼쪽에 chevron 이 있고, **펼침 = 아래(90도 회전) / 접힘 = 오른쪽** 인가
- [ ] 헤더를 클릭하면 그 섹션의 행이 접히고 다시 클릭하면 펼쳐지는가
- [ ] **접은 상태에서도 카운트 배지가 계속 보이는가** (접힌 Staged 의 개수가 숨으면 오커밋 위험 — 필수)
- [ ] 목록을 스크롤할 때 현재 섹션 헤더가 **상단에 달라붙고**(sticky), 다음 섹션 헤더가 올라오면 밀려나는가
- [ ] sticky 로 붙은 헤더 **뒤로 행 글자가 비쳐 보이지 않는가**(배경 불투명 확인)
- [ ] 행이 헤더보다 **오른쪽으로 들여쓰기(pl-4)** 되어 계층이 보이는가
- [ ] 헤더 위에 마우스를 올리면 Stage All / Unstage All 아이콘이 나타나고, 클릭했을 때
      **섹션이 접히지 않고** 액션만 실행되는가
- [ ] 앱을 껐다 켜면 접힘이 초기화되어 **Stashes 만 접힌 상태**로 돌아오는가
- [ ] 사이드바 뷰를 파일/검색으로 바꿨다 git 으로 돌아왔을 때 접어 둔 섹션이 **그대로 접혀 있는가**
- [ ] 프로젝트를 바꿔도 접힘이 유지되는가(의도된 동작 — 프로젝트별 분리가 아니다)

## 5. 키보드 (포커스 이동)

- [ ] 헤더가 Tab 으로 포커스를 받고, 포커스 시 배경이 바뀌는가
- [ ] 헤더에 포커스가 있을 때 hover 액션이 **키보드만으로도** 나타나는가(focus-within)
- [ ] 헤더에서 **Enter/Space** 로 접기·펼치기가 되는가
- [ ] 헤더에서 **→ 로 펼치고 ← 로 접는가**(이미 펼쳐진 상태의 →, 접힌 상태의 ← 는 아무 일도 안 함)
- [ ] ↓ 를 계속 누르면 헤더 → 그 섹션 행들 → 다음 섹션 헤더 → … 순서로 **끊김 없이** 내려가는가
- [ ] ↑ 로 올라올 때도 같은 순서를 역순으로 지나는가, 양 끝에서 순환하지 않고 멈추는가
- [ ] 접은 섹션의 행은 ↓↑ 로 **건너뛰는가**(포커스가 사라지지 않아야 한다)
- [ ] Graph 섹션 헤더까지 로빙으로 도달하는가, 그 아래 커밋 행은 로빙에 들어오지 않는가(기존 동작 유지)

## 6. 테마 대비 (헤더 정적 배경을 쓰지 않은 이유 검증)

> `theme-system.md` §8.2.2·§8.2.4 가 기록한 vsix 임포트 테마의 list 상태 배경 충돌 때문에 헤더에
> 배경 톤을 넣지 않았다. 아래 테마들에서 **구분선 + sticky + 들여쓰기만으로** 헤더가 행과 구분되는지 본다.

- [ ] TAIDE Dark / TAIDE Light
- [ ] Dark+ / Light+
- [ ] Darcula
- [ ] Night Owl
- [ ] Everforest
- [ ] 임포트한 vsix 테마 1종 이상(있으면)
- [ ] 각 테마에서 헤더 hover 배경과 행 hover 배경이 구분되는가, 헤더 구분선이 보이는가

## 7. 회귀 (기존 동작 보존)

- [ ] 행 클릭 = Open Changes(diff preview 탭)가 그대로 동작하는가
- [ ] 행 우클릭 컨텍스트 메뉴 7종이 그대로 나오는가
- [ ] Stage / Unstage / Discard(확인 다이얼로그) 가 그대로 동작하는가
- [ ] 충돌이 있을 때 커밋이 차단되고 안내가 뜨는가
- [ ] staged 0건 + unstaged 있음에서 커밋 시 "전체 스테이지 후 커밋" 확인 다이얼로그가 뜨는가
      (**Staged 섹션을 접어 둔 상태에서도** 동일해야 한다)
- [ ] Graph 커밋 행 클릭 → 커밋 상세 패널이 열리고, 파일 클릭 시 diff 탭이 열리는가
- [ ] Graph 섹션을 접으면 커밋 상세 패널도 함께 숨는가
