# Bun 파일별 격리 테스트 부채

## 대상 파일

- `package.json`의 `test` 스크립트와 `src/**/*.test.ts`, `src/**/*.test.tsx`

## 리포트

CI #88 복구 과정에서 Bun 1.3.14의 `bun test --isolate`를 로컬에서 한 번 실행했을 때 2,899 pass·34 fail·3 errors였습니다. 일반 비격리 실행에 없던 실패로, 여러 테스트가 다른 파일의 전역 mock이나 환경 설정에 의존한다는 위험을 드러냅니다. 이번 v0.3.0의 7건 복구와 별도 작업이며 `--isolate`를 CI에 넣지 않습니다.

## 상세와 재검증 시점

- [ ] 재현: Bun 1.3.14에서 `bun test --isolate`를 실행해 파일별 실패 원인을 모듈 목·전역 상태·IPC shim으로 분류합니다.
- [ ] 수정: 대상 파일이 자기 fixture를 독립적으로 설정하고 정리하게 바꾼 뒤 파일별 격리를 다시 검증합니다.
- [ ] 전환: 비격리와 격리 검사가 모두 성공할 때에만 기본 test 스크립트 전환을 검토합니다.

릴리스 중에는 원격 CI의 기존 비격리 검사를 합격 게이트로 유지합니다. 격리 전환 작업을 시작할 때 위 세 항목을 실행합니다.
