# Rust-native 남은 배치 계획

기준: 2026-10-10, HEAD `0a7d5521`과 배치 22 작업 트리. 사용자가 반복되는 48.6%의 정확성, 무한 반복 여부, 마지막 배치 번호를 요청해 남은 범위를 고정했습니다. 이 문서는 메인이 정한 실행 계획이며 전체 요구사항을 새로 추가하거나 사용자의 미결 결정을 대신 확정하지 않습니다.

## 끝점과 범위

현재 배치는 23이며 배치 22는 완료했습니다. 최종 배치는 33입니다. 남은 기능을 배치 23~~30에서 구현하고 31~~33에서 구조·통합·실기·출시·제거 게이트를 마칩니다. 세부 버그 수정·테스트·파일 수 때문에 새 배치 번호를 만들지 않고 해당 범위의 하위 작업으로 처리합니다. 기능의 완료 조건은 원본 TS 화면·상태·상호작용과 실제 앱 소비·검증이며 원본 버그·내부 수치를 강제로 재현하지 않습니다.

기능표의 웹 기술/내부 지표 10행과 사용자 동결 1행을 제외한 분모는 588행입니다. 기존 검증 근거로 닫힌 286행을 제외한 302행을 [배정 스냅샷](2026-10-10-native-remaining-batch-plan.json)에 ID별로 배정했습니다. 기존 기능표의 각 잔여 행은 정확히 한 배치에 속합니다. 같은 구현을 참조하는 여러 행도 원래 요구사항 ID를 유지하며, 의존 관계로 앞선 배치에서 함께 닫으면 원래 배정과 완료한 배치를 기록합니다.

## 완료 관리

각 배치에서는 ID별 실제 앱 경로와 해당 동작을 덮는 검사 근거를 붙이고 변경한 크레이트의 전체 테스트 대상을 `--no-fail-fast`로 직접 1회 실행합니다. 같은 입력·코드·환경의 성공 검사는 재사용하며 코드 변경이나 확인된 미해결 위험이 있을 때만 관련 검사를 재실행합니다. 동일 가정이 세 번 실패하면 원인을 진단하고 필요한 결정을 올립니다. 검증한 논리 단위만 선별 커밋·일반 푸시합니다.

배치 22 editor-41·editor-79는 원본 Read More 마우스 버튼의 누락 정정/연결·실제 Consumer와 수정 영향 UI 420/App 770건 전체 성공까지 확인해 complete입니다. 최초 배정 302행 중 2행을 닫아 현재 588대상·288완료·잔여 300행이며 배치 23~~30 배정과 최종 33을 유지합니다. 전체 전환율이 아닙니다. 선별 Git 종료 뒤 배치 23을 이어가고 원인 미확정 최초 macOS 이미지 호스트 대기 부채/실기/성능/출시/제거 게이트는 배치 31~~33에 보존합니다.

진척 보고는 마지막으로 닫은 기능, 현재 연결/검증 중인 기능, 남은 요구사항과 전체 게이트를 먼저 적습니다. 복합 요구사항 행의 비율·배치 체크리스트 비율·검사 개수는 전체 전환율을 대신하지 않습니다. 현재 전체 전환율과 신뢰할 잔여시간은 미산정입니다.

배치 23의 editor-30 완료 후 최신 기능표는 588대상·289완료·299미완료입니다. 배치 23의 최초 33행 중 미완료는 32행입니다. 외부 문서/선택/저장 포맷과 raw 전체 교체의 선택·undo, 일반/wrap/접기의 상대 커서 세로 위치를 검증했습니다. editor-49는 내장 공급자가 남아 partial, editor-32의 자동 입력/붙여넣기는 missing을 유지합니다. 프로젝트 열기 5초 초과 두 실패와 직접 검사 두 성공, 성공한 검사 중 FSEvents 등록 RPC 대기는 배치 31 신뢰성 게이트에 보존하며 근본 원인 해결로 처리하지 않습니다. 현재 배치 23·최종 33·배정 누락/중복 0과 전체 전환율·잔여 시간 미산정을 유지합니다.
