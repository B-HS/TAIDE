### 2. [terminal-fit-min-clamp-2x1-pty] `src/features/terminal/terminal-view.tsx:292` — TerminalView → ResizeObserver rAF 콜백 / `fit.fit()`

- 관점: monaco-xterm / 분류: zero-size-layout / finder: major·medium
- 시나리오: 한 창 안에서 pane 을 세로로 2~3번 split 해 터미널 탭을 띄운 뒤(각 pane `minSize={MIN_PANEL_SIZE_PX}` = 120px, src/shared/constants/layout.ts:18), 창 높이를 minSize 합계보다 훨씬 작게 줄인다. 그룹이 minSize 합보다 작으면 minSize 를 지킬 수 없으므로 각 pane 이 120px 아래로 눌리고, 거기서 다시 pane-node-view.tsx 의 탭바(h-8 = 32px)를 빼면 `paneContentRef` content box 높이가 0~수 px 가 된다. 그 순간 ResizeObserver 가 발화한다. - 제안 수정: `Number.isFinite` 검사에 더해 fit addon 의 클램프 하한을 탐지하는 가드를 둔다. 예: rAF 콜백 진입 시 `const rect = container.getBoundingClientRect(); if (rect.width < 1 || rect.height < 1) return`, 또는 `dimensions.cols <= 2 || dimensions.rows <= 1` 이면 `fit()` 을 건너뛰고 다음 ResizeObserver 발화를 기다린다. 같은 가드를 line 176/183 의 fontSize/fontFamily effect 가 호출하는 `fitRef.current?.fit()` 에도 공통 헬퍼로 적용한다.
- 검증 판정: **REAL / major** — Traced the full chain in source, not just the finding's claims.
