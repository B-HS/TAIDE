| 번호 | 반영한 수정 | 회귀 근거 |

## 검증과 제약

- 전체 `bun run verify` 종료 코드 0: 타입·린트·포맷·Rust fmt/clippy 통과, Bun 2,949개·Rust 1,775개 성공, 실패 0건.
- 프론트엔드 프로덕션 빌드와 E2E 프로젝트 타입 검사를 실행했습니다.
- CI의 Bun 1.3.14에서도 프론트엔드 2,949개가 통과했습니다. Happy DOM이 덮어쓴 WebSocket 대신 런타임 기본 WebSocket을 보존하고, 단위 검사에서 CSS를 실제 네트워크로 다운로드하지 않도록 격리했습니다. 실제 HTML 리소스 로드는 별도의 WebKit·Chrome 검사로 확인했습니다.
- HTML 미리보기는 스크립트·폼·중첩 프레임을 차단합니다. `allow-same-origin`만 허용해 Chrome의 원격 인증 쿠키 차단을 해결했으며 `allow-scripts`는 허용하지 않습니다.
- LSP의 프로젝트 루트 사이 파일 이동은 디스크 변경 전에 명시적으로 거부합니다. 프로젝트 내부 이름 변경·폴더 이동은 지원합니다.
- 테스트는 격리된 파일·Git 저장소·HTTP/WebSocket 서버와 브라우저를 사용했습니다. 사용자의 실제 GitHub 동기화 자료·키체인·운영 원격 세션은 조작하지 않았습니다. 실제 앱의 모든 조합을 수동 E2E로 실행했다는 의미는 아닙니다.
