## TAIDE v0.1.8 — Claude Code Ctrl+G 수정 · MIT 라이선스 · README (macOS Apple Silicon)

Claude Code 의 Ctrl+G 외부 편집이 실제로 TAIDE 탭으로 열리도록 고치고, 프로젝트를 MIT 로 공개한 릴리스입니다.

### 고쳐진 것

- **Claude Code Ctrl+G 가 "Open a project first" 로 끝나던 문제**: Claude Code 가 넘기는 임시파일은 어떤
  프로젝트 폴더에도 속하지 않아 열리지 않았습니다. 이제 CLI 로 전달된 파일은 활성 프로젝트의 탭으로 열리고,
  저장한 뒤 탭을 닫으면 Claude Code 로 내용이 돌아갑니다. 열릴 때 안내 토스트가 뜨며, 이 탭에는 언어 서버·
  저장 시 포맷·코드 액션이 붙지 않아 Claude Code 가 붙인 `#` 주석 문맥이 그대로 보존됩니다.
- 위 파일은 preview 탭이 아닌 고정 탭으로 열려, 다른 파일을 미리보기로 열어도 대기 중인 Claude Code 가 끊기지
  않습니다.

### 라이선스 · 문서

- 프로젝트 라이선스를 **MIT** 로 명시했습니다(`LICENSE`). 번들 테마·문법·라이브러리 고지는
  `THIRD_PARTY_LICENSES.md` 에 정리돼 있습니다.
- 저장소에 `README.md` 를 추가했습니다(기능·설치·Claude Code 연동·단축키·개발 안내).

### 설치

1. `TAIDE_0.1.8_aarch64.dmg` 를 내려받아 열고 TAIDE 를 Applications 로 드래그합니다.
2. Developer ID 서명·Apple 공증이 완료된 빌드라 별도 허용 절차 없이 바로 실행됩니다.
3. 무결성 확인(선택): `shasum -a 256 -c SHA256SUMS.txt`

Ctrl+G 연동은 이 설치본으로 확인해 주세요. TAIDE 터미널에서 `claude` 를 실행하면 EDITOR 가 자동 주입되고,
다른 터미널에서는 `export EDITOR="taide --wait"` 로 같은 동작을 얻습니다(명령 팔레트 "Shell Command: Install
'taide' command in PATH" 로 CLI 설치).

요구 사항: macOS (Apple Silicon)
