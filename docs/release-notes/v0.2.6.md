## TAIDE v0.2.6 — 파일 보호·저장·원격 연결 안정화 (macOS Apple Silicon)

전체 점검으로 확인한 사용자 기능 버그 14건을 수정한 유지보수 릴리스입니다.

### 파일·편집

- 심볼릭 링크를 이름 변경하거나 삭제할 때 원본 대신 링크 자체를 처리합니다.
- 언어 서버가 파일을 이름 변경하면 열린 탭·편집 버퍼·복구용 임시 저장도 새 경로를 따릅니다. 저장하지 않은 파일의 자동 삭제는 거부합니다.
- 자동 저장 중 추가로 입력한 내용도 다음 저장에 반영합니다.
- 언어 서버의 같은 위치 삽입 순서와 줄 끝을 넘는 편집 범위 계산을 바로잡았습니다.

### Git·작업 실행

- 끊어진 링크와 폴더 링크를 올바른 링크 항목으로 스테이징합니다.
- Git 비교 화면에서 읽기 실패를 파일 삭제로 표시하지 않습니다.
- Makefile 한 규칙에 여러 대상이 있으면 각각 실행할 수 있습니다.

### 원격·동기화·미리보기

- 연결 실패로 거절된 원격 명령을 나중에 다시 실행하지 않습니다. 재연결 후 터미널·언어 서버·화면 데이터를 복구합니다.
- GitHub 동기화를 다시 연결하거나 새 기기에서 연결할 때 기존 동기화 Gist를 찾습니다.
- 기본 글꼴로 되돌린 설정도 동기화하며, 다른 창이나 설정 파일의 언어·테마 변경이 화면에 반영됩니다.
- HTML 미리보기에서 상대 경로 CSS와 이미지가 표시됩니다. 스크립트·폼 제출·중첩 프레임은 차단합니다.

### 설치

1. `TAIDE_0.2.6_aarch64.dmg`를 내려받아 열고 TAIDE를 Applications로 드래그합니다.
2. Developer ID 서명·Apple 공증이 완료된 빌드입니다.
3. 무결성 확인(선택): `shasum -a 256 -c SHA256SUMS.txt`

요구 사항: macOS (Apple Silicon)
