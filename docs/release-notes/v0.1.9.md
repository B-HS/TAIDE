## TAIDE v0.1.9 — 에이전트 상태 감지 개편 · 터미널 안정화 · 시크릿 마스킹 (macOS Apple Silicon)

내장 터미널에서 돌리는 Claude Code 의 상태 배지가 실제 상태를 즉시 반영하도록 감지 계층을 다시 만들고, 터미널·검색·파일 감시의 결함을 한 묶음으로 손본 릴리스입니다.

### 에이전트 상태 배지

- **권한 프롬프트가 떠 있는데 유휴(빈 원)로 보이던 문제**: 이제 hooks 를 켜지 않아도 `Do you want to proceed?` 류 다이얼로그가 뜨면 1초 안에
  노란 마름모(입력 대기)로 바뀌고, 답하면 파란 점(작업 중), 턴이 끝나면 초록 빈 원(유휴)으로 돌아옵니다. 다른 프로젝트 탭에 가 있어도
  사이드바 아이콘과 터미널 탭 아이콘이 같은 상태를 보여줍니다.
- 작업 중 판정이 프로세스 CPU 상태가 아니라 터미널 출력·타이틀·다이얼로그 문구·사용자 입력을 근거로 바뀌어, API 응답을 기다리는 동안
  유휴로 떨어지던 흔들림이 사라졌습니다. 유휴 진입은 조용해진 뒤 4초입니다.
- Claude Code hooks 를 켠 프로젝트는 훅이 그 터미널 세션 안으로 직접 이벤트를 넣습니다(로컬 HTTP 서버·포트·토큰 불필요). 권한 요청은
  즉시 반영되고, 같은 프로젝트에 터미널을 여러 개 열어도 세션끼리 상태가 섞이지 않습니다. 기존에 설치돼 있던 훅 항목은 프로젝트를 열 때
  자동으로 새 형식으로 교체됩니다. Codex·Gemini 훅은 종전 방식 그대로입니다.

### 터미널

- 터미널 탭을 오갈 때 스크롤백 재생 때문에 실행 중인 프로세스가 잠깐 멈추던 문제를 없앴습니다.
- 스크롤백이 가득 찬 뒤 탭을 다시 열면 첫 화면이 깨진 문자로 시작하던 문제를 고쳤습니다.
- 파일 링크는 실제로 존재하는 파일에만 밑줄이 생깁니다(버전 문자열·`host:port` 같은 오탐 제거). 좌표 표기는 `file.ts:12:3` 외에
  `file.ts(12,3)`·`file.py", line 42`·`#L42`·`:10-20` 도 인식해 해당 줄·열로 엽니다.
- 빈 프롬프트에서 Enter 나 Ctrl-C 를 눌러도 명령 블록 장식(거터 색 막대)이 생기지 않습니다.
- zsh 에서 백슬래시가 든 디렉터리의 현재 경로 보고가 훼손되던 문제와 `~user` 경로 해석 오류를 고쳤습니다.

### 명령 팔레트

- 파일 퀵오픈·커맨드 검색에서 `search panel` 처럼 공백으로 나눈 여러 단어를 입력할 수 있습니다(모든 단어가 각각 매치되는 항목만 표시).

### 설치

1. `TAIDE_0.1.9_aarch64.dmg` 를 내려받아 열고 TAIDE 를 Applications 로 드래그합니다.
2. Developer ID 서명·Apple 공증이 완료된 빌드라 별도 허용 절차 없이 바로 실행됩니다.
3. 무결성 확인(선택): `shasum -a 256 -c SHA256SUMS.txt`

에이전트 배지는 내장 터미널에서 `claude` 를 실행해 권한 프롬프트를 띄워 보면 확인할 수 있습니다. hooks 를 쓰려면 설정의 "에이전트 hooks"
를 켜고 프로젝트별로 설치하면 됩니다.

요구 사항: macOS (Apple Silicon)
