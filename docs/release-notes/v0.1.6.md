## TAIDE v0.1.6 — Claude Code Ctrl+G 연동·팔레트 입력 수정 (macOS Apple Silicon)

에이전트 연동·입력 사용성 릴리스입니다. 내장 터미널의 Claude Code Ctrl+G 가 TAIDE 로 열리고,
커맨드 팔레트의 첫 타이핑이 프리픽스를 지우던 문제가 고쳐졌습니다.

### 새 기능

- **Claude Code Ctrl+G 를 TAIDE 로**: 내장 터미널에서 Claude Code 의 Ctrl+G(외부 에디터)를
  누르면 vim 대신 현재 TAIDE 창에 탭으로 열리고, 탭을 닫으면 Claude Code 로 반영됩니다.
  새로 여는 터미널에 `EDITOR`/`VISUAL` 이 자동 설정되며, 셸 설정(rc)에 직접 export 한 값이
  있으면 그것이 우선합니다. 팔레트 커맨드 "Claude Code Ctrl+G 를 TAIDE 로 연결" 이 CLI
  설치까지 한 번에 처리합니다.

### 고쳐진 것

- 커맨드 팔레트(⌘⇧P)가 열릴 때 ">" 프리픽스가 전체선택 상태로 시작해 첫 타이핑이 프리픽스를
  지우던 문제 — 이제 캐럿이 끝에 놓여 바로 입력할 수 있습니다.

### 확인된 것

- git 변경 목록의 "빈 폴더" 표시 의혹은 조사 결과 버그가 아니었습니다 — 빈 폴더·ignored
  파일만 든 폴더는 원래 표시되지 않으며(git CLI 와 동일), 이 동작을 회귀 테스트로 고정했습니다.

### 설치

1. `TAIDE_0.1.6_aarch64.dmg` 를 내려받아 열고 TAIDE 를 Applications 로 드래그합니다.
2. Developer ID 서명·Apple 공증이 완료된 빌드라 별도 허용 절차 없이 바로 실행됩니다.
3. 무결성 확인(선택): `shasum -a 256 -c SHA256SUMS.txt`

요구 사항: macOS (Apple Silicon)
