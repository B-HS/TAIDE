## TAIDE v0.1.3 — 안정성·성능 대규모 정비 (macOS Apple Silicon)

전수조사(6축 감사) 기반 정비 릴리스입니다. 버그 41건 수정, 검색·기동·대형 파일 성능 개선,
에디터 설정 10종 신설이 담겼습니다.

### 고쳐진 것 — 데이터 안전

- 미저장 편집이 탭 전환·재시작 복원 직후 디스크 내용으로 되돌아가던 문제 (핫엑시트 복원 순서 역전)
- 탐색기 붙여넣기·이름 변경이 접힌 폴더 안의 기존 파일을 확인 없이 덮어쓰던 문제,
  대소문자만 바꾸는 이름 변경이 무시되던 문제
- EUC-KR 등 비 UTF-8 파일을 열어 저장하면 원본이 영구 손상되던 문제 (읽기 전용으로 안전 차단)
- merge 충돌 상태에서 커밋하면 충돌 마커가 그대로 커밋되던 문제 (커밋 차단·안내)
- 검색 Replace All 이 화면에 보이는 결과가 아니라 클릭 시점 입력값으로 치환되던 문제
- 이름 변경·삭제 후 열린 탭이 따라가지 않고, 폴더 개명 후 저장이 옛 경로를 되살리던 문제

### 고쳐진 것 — 기능

- 터미널 탭 복귀 시 세션이 유지되지 않고 매번 새 셸이 뜨던 문제 (재부착 복원)
- pinned 탭이 버튼·⌘W·미들클릭으로 닫히던 문제, 한글 입력(IME) 조합 중 단축키·검색 Enter
  오발동, 보조 창에서 ⌘K ⌘S 무반응
- git: 새 폴더 stage 상시 실패, staged rename diff 가 전체 추가로 보이던 문제, 외부 변경 시
  diff 탭 미갱신, `build`·`dist` 이름의 파일·브랜치 변경이 영영 반영되지 않던 문제
- 활성 테마 삭제 후 하이라이트가 전멸하던 문제, VSIX 테마 저장 시 정밀 토큰 규칙 소실
- 설정 저장 실패가 무음이던 문제, 프로젝트 전환 시 검색·커밋 메시지 교차 잔존 등 총 41건

### 빨라진 것

- 전역 검색: 병렬 스캔 + 결과 배칭 전환 — 대형 프로젝트에서 체감 큰 폭 개선, 거대 파일로 인한
  메모리 스파이크·취소 불가 해소
- 기동: PDF·스프레드시트 등 무거운 미리보기 모듈과 문법 데이터를 필요 시점에 로딩
- 대형 파일 열기·저장·폴더 복사 중 앱 전체가 잠기던 지점 해소, 터미널 고출력·패널 리사이즈
  드래그의 버벅임 개선, 닫은 탭의 메모리 누수 정리

### 새 기능 — 에디터 설정 10종 (기본 꺼짐, 설정에서 켭니다)

- diff 미변경 영역 접기·코드 이동 감지, 브래킷 페어 가이드선, 스무스 스크롤·커서 애니메이션,
  자동완성 인라인 미리보기, 세로 눈금선(rulers)
- 저장 시 후행 공백 제거·마지막 줄바꿈 삽입, `.editorconfig` 지원(들여쓰기·저장 정리 규칙)

### 설치

1. `TAIDE_0.1.3_aarch64.dmg` 를 내려받아 열고 TAIDE 를 Applications 로 드래그합니다.
2. Developer ID 서명·Apple 공증이 완료된 빌드라 별도 허용 절차 없이 바로 실행됩니다.
3. 무결성 확인(선택): `shasum -a 256 -c SHA256SUMS.txt`

요구 사항: macOS (Apple Silicon)
