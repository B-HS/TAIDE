## TAIDE v0.2.5 — 트리 다중 선택 · 파일 탭 재사용 · 포커스 복귀 안정화 (macOS Apple Silicon)

파일과 Git 변경 목록을 여러 개 선택할 수 있게 하고, 파일을 열 때 탭이 예상치 않게 교체되거나 중복되던 동작을 정리한 유지보수 릴리스입니다. 앱으로 돌아올 때 화면이 갑자기 리프레시되는 현상과 알림 전달 안내에 불필요한 설정 버튼이 계속 보이던 문제도 함께 수정했습니다.

### 파일·Git 트리

- 파일 트리와 Git 변경 목록에서 Shift+클릭으로 연속 범위를 선택할 수 있습니다.
- Command+클릭으로 항목을 기존 선택에 추가하거나 선택에서 해제할 수 있습니다. 다른 플랫폼에서는 Ctrl+클릭도 같은 방식으로 동작합니다.
- 다중 선택을 위한 modifier 클릭은 파일이나 diff를 열지 않고 선택만 바꿉니다.
- 키보드 탐색, 일반 클릭, 컨텍스트 메뉴와 선택 상태의 접근성 표시는 기존 동작을 유지합니다.

### 파일·diff 탭

- 파일 트리와 Git 변경 목록에서 연 파일과 diff는 더 이상 다른 미리보기 탭을 교체하지 않고 일반 탭으로 유지됩니다.
- 현재 창의 다른 편집 그룹에 이미 같은 파일 탭이 열려 있으면 새 중복 탭을 만들지 않고 그 탭으로 이동합니다.
- Git diff 탭과 일반 파일 탭은 경로가 같아도 서로 다른 탭으로 유지됩니다.
- “옆에 열기”처럼 명시적으로 화면 분할을 요청한 경우에는 기존처럼 같은 파일을 다른 그룹에 열 수 있습니다.

### 창·알림

- 앱이 백그라운드에서 다시 포커스를 받을 때 같은 macOS appearance를 불필요하게 재적용하지 않습니다. 다른 창에서 실제 appearance가 바뀐 경우에만 현재 테마로 동기화합니다.
- OS 알림 전달 성공 뒤 표시되는 안내 toast에서 “알림 설정 열기” 버튼을 제거했습니다. 알림 설정 화면의 명시적 시스템 설정 버튼은 그대로 유지됩니다.

### 알려진 제약

- 현재 알림 플러그인은 macOS의 실제 알림 권한 상태를 반환하지 않습니다. 권한 확인이나 변경은 설정 화면의 “알림 설정 열기”에서 직접 확인해야 합니다.

### 설치

1. `TAIDE_0.2.5_aarch64.dmg`를 내려받아 열고 TAIDE를 Applications로 드래그합니다.
2. Developer ID 서명·Apple 공증이 완료된 빌드라 별도 허용 절차 없이 바로 실행됩니다.
3. 무결성 확인(선택): `shasum -a 256 -c SHA256SUMS.txt`

요구 사항: macOS (Apple Silicon)
