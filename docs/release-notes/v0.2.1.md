## TAIDE v0.2.1 — git 패널 크래시 수정 · 안정성 보강 · 부팅 스플래시 (macOS Apple Silicon)

사이드바 git 뷰를 처음 열거나 프로젝트를 전환할 때 패널이 오류 화면으로 바뀌던 문제를 고친 유지보수 릴리스입니다. 같은 종류의 문제를 앱 전체에서 다시 점검해 AI 커밋 메시지·터미널·클립보드·PDF 미리보기·에디터 포커스 쪽을 함께 손봤고, 앱이 뜨는 동안 로고와 이름이 보이는 부팅 화면을 넣었습니다.

### git 패널

- git 뷰를 처음 열거나 git 뷰가 열린 채 다른 프로젝트로 전환하면 "Sidebar Panel — Something went wrong" 오류 화면이 뜨고 Retry 를 눌러야 했던 문제를 고쳤습니다. 커밋 그래프 영역이 목록보다 늦게 마운트될 때 내부 레이아웃 등록보다 먼저 접힘 상태를 적용하려다 실패하던 것이 원인입니다.
- AI 커밋 메시지를 생성하는 도중 다른 프로젝트로 전환하면, 앞 프로젝트의 변경을 요약한 메시지가 뒤 프로젝트의 커밋 입력창에 들어가던 문제를 고쳤습니다. 전환 시 진행 중인 생성은 취소됩니다.
- 사이드바 너비를 키보드로 조절할 때 키 반복마다 레이아웃 저장 요청이 나가던 것을 접힘 상태가 실제로 바뀔 때만 한 번 저장하도록 바꿨습니다.

### 터미널

- 세로로 여러 번 분할한 터미널이 창 축소로 높이 0 에 가깝게 눌리면 셸에 2열×1행 크기가 전달되어 Claude Code 같은 TUI 화면이 깨지던 문제를 고쳤습니다. 측정할 수 없는 크기에서는 리사이즈를 보내지 않고, 영역이 다시 커지면 정상 크기로 맞춥니다. 이미 눌린 영역에서 터미널 탭을 새로 열 때도 같은 규칙이 적용됩니다.

### 에디터 · 미리보기

- 세션 복원이나 화면 분할로 에디터가 여러 개 동시에 열릴 때, 마지막에 열린 에디터가 포커스를 가져가 실제로 포커스된 영역과 어긋나던 문제를 고쳤습니다. 파일 확장자만 바뀌었을 때 커서가 터미널이나 검색창에서 에디터로 끌려오던 것도 없앴습니다.
- PDF 미리보기: 보고 있는 파일이 외부에서 다시 저장되면 새 내용으로 다시 그립니다. 페이지 이동 직후 탭을 닫을 때 남던 내부 오류도 처리했습니다.

### 클립보드 · 명령 팔레트

- 탐색기·탭·git 패널·사이드바의 "경로 복사"가 실패하면(클립보드 접근 거부, 원격 미러의 비보안 접속 등) 실패 토스트를 띄웁니다. 이전에는 아무 표시 없이 조용히 실패했습니다.
- 명령 팔레트에서 실행한 비동기 명령이 실패하면 오류 토스트로 알립니다.

### 부팅 화면

- 앱이 시작되는 동안 검은 배경 정중앙에 TAIDE 로고와 이름이 표시되고, 화면이 준비되면 짧게 사라집니다.

### 내부 정리

- 화면을 여러 프로젝트로 분할했을 때 각 영역의 패널 요소가 같은 HTML id 를 갖던 문제를 고쳐 접근성 연결(`aria-controls`)이 올바른 영역을 가리키게 했습니다.
- 토스트 영역을 툴팁 프로바이더 안으로 옮겨, 앞으로 버튼이 든 토스트가 앱 전체를 멈추지 못하게 했습니다.
- 응답을 기다리지 않는 내부 호출들의 실패 처리를 통일했습니다.

### 알려진 제약

- 부팅 화면은 보조 창을 열 때도 잠깐 표시됩니다.
- PDF 파일이 외부에서 바뀌면 다시 그리는 동안 로딩 표시가 잠깐 보입니다.

### 설치

1. `TAIDE_0.2.1_aarch64.dmg` 를 내려받아 열고 TAIDE 를 Applications 로 드래그합니다.
2. Developer ID 서명·Apple 공증이 완료된 빌드라 별도 허용 절차 없이 바로 실행됩니다.
3. 무결성 확인(선택): `shasum -a 256 -c SHA256SUMS.txt`

요구 사항: macOS (Apple Silicon)
