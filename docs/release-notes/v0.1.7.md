## TAIDE v0.1.7 — 사용성 배치 3·4: 퀵오픈·링크·자동 reveal 수정, OS 알림·메뉴·성능·테스트 (macOS Apple Silicon)

버그 3건의 근본 수정과 기능 7건, 성능 계측·최적화, 테스트 하네스·CI 를 한 번에 담은 릴리스입니다.

### 고쳐진 것

- **⌘P 파일 열기 "찾을 수 없는 파일"**: 앱 안에서 파일을 만들거나 지우거나 이름을 바꾸면 파일 검색
  인덱스가 즉시 갱신되고, 사라진 파일을 열려 하면 빈 탭 대신 "파일을 찾을 수 없습니다" 안내가 뜹니다
  (Claude Code 의 파일 열기 요청도 같은 검증을 거칩니다).
- **터미널 링크가 앱 창 안에서 열리던 문제**: 터미널·마크다운 프리뷰의 외부 링크는 항상 OS 기본
  브라우저로 열립니다. `gh`·`vite`·Claude Code 가 출력하는 하이퍼링크(OSC 8)도 ⌥/⌘ 클릭으로 열립니다.
  앱 창은 자기 오리진 밖으로 이동하지 않도록 WebView 수준에서 막았습니다.
- **git 목록 키보드 이동 시 sticky 헤더가 행을 가리던 문제**, 프로젝트 열기 중 내부 오류가 조용히
  넘어가던 경로.

### 새 기능

- **탐색기 자동 reveal**: 파일을 열거나 탭을 바꾸면 파일 트리가 해당 파일을 펼쳐 선택합니다
  (설정 → 인터페이스 → "탐색기에서 활성 파일 자동 표시", 기본 켜짐).
- **OS 알림**: 창이 비활성일 때 에이전트 작업 완료·긴 터미널 명령 완료(백그라운드 탭 포함)·git
  push/pull·검색 치환·LSP 설치 결과를 macOS 알림으로 받습니다. 설정 → 알림에서 카테고리별로 켜고
  끌 수 있고 "알림 설정 열기"·"테스트 알림" 버튼이 있습니다.
- **Welcome**: ⌘⇧P "View: Welcome" 커맨드, 프로젝트에 열린 탭이 없으면 편집 영역에 Welcome 이
  표시됩니다(설정으로 끌 수 있음).
- **프로젝트 목록 표시 설정**: 좌측 프로젝트 아이콘을 우클릭해 아이콘(56종)·1~4자 텍스트 라벨·색을
  고를 수 있습니다.
- **git 패널 섹션 정리**: Merge → Staged → Changes → Stashes → Graph 순, 접이식 sticky 헤더와 개수
  뱃지, 빈 Stash 섹션은 표시하지 않고 Stash 버튼은 상단 바로 이동. 방향키로 헤더까지 이동하고 ←/→ 로
  접고 펼칩니다.
- **터미널 우클릭 메뉴**: 위/아래/왼쪽/오른쪽으로 새 터미널 분할(공간이 부족한 방향은 비활성),
  복사·붙여넣기·모두 선택·지우기·새 터미널·종료.
- **탭 바 여백 우클릭 메뉴**: 새 파일·새 터미널·닫은 탭 다시 열기·저장된 탭 닫기·모든 탭 닫기·분할·
  Welcome 열기. 파일 탭 메뉴에 "이름 바꾸기" 추가.

### 성능

- 팔레트 파일 검색 매칭 약 5.6배, 테마 목록 조회 약 18배, git 상태 재조회는 캐시 히트 시 수백 배
  빨라졌고, 파일 워처 메모리가 프로젝트당 약 100MB 에서 0.2MB 수준으로 줄었습니다. 프로젝트 열기
  중 다른 작업이 막히던 구간을 크게 줄였습니다.
- git 변경 목록·아웃라인은 가상화되어 큰 저장소에서도 스크롤이 가볍습니다.
- `TAIDE_PERF=1` 로 실행하면 부팅·파일 열기·팔레트·트리·검색·터미널 처리량 계측을 볼 수 있습니다.

### 내부

- 컴포넌트·훅 테스트 하네스(happy-dom + Testing Library) 도입, 단위 테스트 2287·Rust 테스트 1435,
  e2e 스펙 25종, push/PR CI 게이트 신설.

### 설치

1. `TAIDE_0.1.7_aarch64.dmg` 를 내려받아 열고 TAIDE 를 Applications 로 드래그합니다.
2. Developer ID 서명·Apple 공증이 완료된 빌드라 별도 허용 절차 없이 바로 실행됩니다.
3. 무결성 확인(선택): `shasum -a 256 -c SHA256SUMS.txt`

요구 사항: macOS (Apple Silicon)
