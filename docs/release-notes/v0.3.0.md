# TAIDE v0.3.0 — Rust 실행 경계 정리 (macOS Apple Silicon)

기존 화면과 사용자 데이터를 유지하면서 주요 기능의 Rust 코드를 독립 crate와 공유 runtime으로 분리한 릴리스입니다. Rust-native 화면으로의 전환은 아직 포함되지 않습니다.

### 실행 구조와 안정성

- 파일·프로젝트·Git·검색·설정·동기화·LSP·터미널·원격·IDE 기능의 정책과 자원 소유권을 기능별 Rust crate 및 명시적 runtime 경계로 정리했습니다.
- Tauri 앱의 기존 명령·이벤트·원격 wire 계약과 저장 데이터 형식을 유지했습니다.
- 종료 시 등록된 watcher·LSP·PTY·감독 작업의 완료를 기다리며, 격리 앱에서 활성 원격 WebSocket·PTY의 직접 종료를 확인했습니다.

### 원격 연결

- 느린 WebSocket 수신자를 위한 연결별 256프레임 전송 큐 상한과 포화 시 연결 종료를 적용했습니다.
- 세션의 7일 만료를 제품 라우터의 가상 시계 검사에서 HTTP 401·WebSocket 종료 코드 4001로 확인했습니다.

### 검증 범위

- 프론트엔드 테스트 2,949건·타입 검사·빌드, Rust workspace 테스트·Clippy·포맷 검사를 통과했습니다.
- 현행 앱의 기능·저장 데이터·IPC 및 대표 화면을 기준선으로 기록했습니다. 부팅 약 1.12초는 실제 첫 픽셀이 아닌 화면 표시 준비 대리지표입니다.
- Rust-native UI, TypeScript·Tauri 제거, 모든 화면의 native 동등성은 후속 M8 범위입니다. 한 실앱에서 모든 종료 자원을 동시에 지연시킨 실측과 OS 강제 종료도 이번 보장 범위에 포함하지 않습니다.

### 설치

1. 이 draft의 빌드가 완료된 뒤 `TAIDE_0.3.0_aarch64.dmg`를 내려받아 열고 TAIDE를 Applications로 드래그합니다.
2. 함께 제공되는 `SHA256SUMS.txt`로 `shasum -a 256 -c SHA256SUMS.txt`를 실행해 무결성을 확인할 수 있습니다.

요구 사항: macOS (Apple Silicon)
