## TAIDE v0.2.0 — 프로젝트 분할·그룹 · 단축키 확장 · 에이전트 다각화 · 테마 정비 (macOS Apple Silicon)

여러 프로젝트를 한 창에서 나란히 열어 두고 그룹으로 묶어 관리하는 기능을 새로 넣고, 탭·분할·탐색기 단축키를 대폭 늘렸습니다. 에이전트 상태 배지가 Claude Code 외에 opencode·codex 도 감지하도록 넓어졌고, 번들 테마 전체의 색상 구별성·대비를 손보면서 새 테마 9종을 추가했습니다. 그 밖에 검색 실시간화, 퀵오픈 결함, 알림 문구, git 패널 등 자잘한 사용성 문제도 함께 정리했습니다.

### 프로젝트 분할 뷰 · 그룹

- 사이드바의 프로젝트 아이콘을 화면 위로 드래그하면 좌/우/상/하로 놓아 화면을 분할할 수 있습니다. 분할된 각 영역은 탐색기·에디터·터미널을 모두 갖춘 독립된 프로젝트 화면입니다. 가운데로 놓으면 그 영역의 프로젝트를 교체합니다. 이미 다른 영역에 열려 있는 프로젝트를 떨어뜨리면 거부 토스트가 뜹니다. 프로젝트 아이콘의 컨텍스트 메뉴에서도 "오른쪽/왼쪽/위/아래에 열기"로 같은 동작을 할 수 있습니다.
- 단축키·타이틀바·상태바·명령 팔레트·터미널 열기 같은 동작은 항상 **마지막으로 클릭하거나 포커스한 분할 영역**을 기준으로 동작합니다. Zen 모드는 포커스된 영역만 남기고 나머지 분할 영역을 숨깁니다.
- 별도 OS 창으로 분리한 보조 창에 탐색기·검색·SCM 패널과 명령 팔레트·작업 러너가 추가되어, 그 창의 프로젝트를 기준으로 동작합니다. 보조 창 탐색기에서 클릭한 파일은 그 창에 열립니다.
- 사이드바에서 여러 프로젝트를 이름과 색을 가진 **그룹**으로 묶을 수 있습니다. 그룹 헤더에서 접기/펼치기, 그룹 전체 열기(첫 프로젝트만 활성화되고 나머지는 활성화 없이 순서대로 열립니다. 사라진 프로젝트는 건너뛰고 결과를 토스트로 알립니다), 이름·색 변경, 삭제(삭제해도 프로젝트 자체는 남습니다)가 가능합니다. 프로젝트 아이콘 컨텍스트 메뉴에서 그룹에 추가하거나 그룹에서 뺄 수 있습니다.

### 단축키 확장

- 탭 이동에 ⌥⌘← / ⌥⌘→ 가 추가됐습니다.
- ⌘K 를 누른 뒤 ⌘←/→/↑/↓ 로 인접한 분할 영역으로 포커스를 옮기고, ⌘K ⌘⇧←/→ 로 현재 탭을 인접 영역으로 옮기고, ⌘K ⌘W 로 포커스된 영역의 탭을 모두 닫고, ⌘1~⌘9 로 N번째 분할 영역에 바로 포커스할 수 있습니다. 에디터에 커서가 있는 상태에서도 동작합니다.
- 키바인딩 에디터가 각 단축키의 적용 범위(터미널 전용 등)를 표시해, 실제로는 겹치지 않는 단축키를 충돌로 잘못 표시하던 문제를 고쳤습니다.
- 탐색기(파일 트리)에 VS Code 와 같은 단축키 세트를 추가했습니다: **Enter = 이름 바꾸기**(동작이 바뀌었습니다 — 폴더 펼치기/접기는 화살표 키나 클릭으로), ⌘↓ = 고정 탭으로 열기, Space = 포커스를 유지한 채 미리보기, ⌘⌫ = 휴지통으로 삭제, ⌘C/⌘X/⌘V = 복사/잘라내기/붙여넣기, ⌘N/⌘⇧N = 새 파일/새 폴더, ⌥⌘R = Finder 에서 보기, ⌥⌘C·⇧⌥⌘C = 경로·상대 경로 복사. 이 단축키들은 아직 재배정할 수 없습니다.
- 탐색기의 빈 공간을 더블클릭하면 프로젝트 루트에 새 파일 초안이 생성됩니다.

### 에이전트 감지

- 상태 배지가 Claude Code 뿐 아니라 **opencode**·**codex** CLI 도 실제 상태(작업 중·입력 대기·유휴)를 즉시 반영합니다. opencode 는 전용 플러그인으로 권한 요청과 유휴 전환을 바로 감지하고, 유휴 중에도 도는 스피너 문자를 작업 중으로 오판하던 문제를 없앴습니다. codex 는 훅 전달 방식을 즉시 반영되는 방식으로 바꿨습니다.
- 배지 툴팁과 알림에 "권한 요청 대기"·"질문 대기" 같은 차단 사유가 표시됩니다. "에이전트 입력 대기" 알림은 "작업 완료" 알림과 별도로 켜고 끌 수 있습니다.
- 설정의 에이전트 훅 목록에 opencode·pi 가 추가됐습니다.

### 테마

- 상태를 나타내는 색이 배경색과 같아서 구별이 안 되던 문제(에디터 드래그 선택, 설정 화면 토글 켜짐 트랙, 터미널 선택 영역, 비활성 선택, 활성 탭, 현재 줄 강조, 버튼 hover 등)를 전 테마에서 점검해 기존 테마 36종의 색상 값을 손질했습니다.
- 글자와 배경의 대비도 전수 점검해 부족한 부분을 자동으로 보정했습니다.
- 메뉴·스크롤바·그림자 등, 정의만 있고 실제 화면에 반영되지 않던 색 토큰을 해당 UI 요소에 연결했습니다. 하드코딩된 흰색/검정색과 동작하지 않는 다크 모드 분기도 정리했습니다.
- 새 테마 9종을 추가해 번들 테마가 38종에서 **47종**이 됐습니다: Catppuccin Latte·Frappé·Macchiato, Tokyo Night Storm·Light, Gruvbox Light, Rosé Pine Moon, Ayu Mirage, GitHub Dark Dimmed.

### 알림 · 메뉴 · 검색 · git 패널 · 퀵오픈 · Welcome

- 알림 문구에 프로젝트 이름·에이전트·경과 시간·탭 제목이 함께 표시됩니다(예: "작업 완료 · 3분 12초").
- 메뉴바에 **File > Open Recent**(최근 10개)와 **Clear Recent** 가 추가됐습니다.
- 사이드바 검색 패널이 입력하는 대로 실시간으로 검색됩니다(디바운스 시간은 설정에서 조정 가능, 기본 300ms). Enter 를 누른 검색만 이력에 남습니다. 검색 결과의 파일 아이콘이 탐색기와 같은 아이콘으로 바뀌었습니다.
- git 패널의 커밋 그래프가 별도 영역으로 분리되어 드래그로 크기를 조절하고 접을 수 있으며, 크기와 접힘 상태가 재시작 후에도 유지됩니다.
- 퀵오픈(⌘P)의 여러 결함을 고쳤습니다: 동점 결과의 정렬 순서 고정, 한글 등 유니코드 정규화 후 매칭(입력 방식이 달라도 찾을 수 있음), 심볼릭 링크 파일 인식, 프로젝트가 없을 때 안내 메시지, 포커스된 편집 영역이 사라졌을 때 첫 영역으로 폴백.
- Welcome 화면에 "터미널 열기" 버튼이 추가됐습니다.
- 사이드바의 "+" 버튼이 드롭다운 메뉴로 바뀌어 경로로 열기(`~` 확장 지원)·Finder 로 열기·최근 프로젝트를 선택할 수 있습니다.
- 컨텍스트 메뉴 하위 메뉴(Split 등)의 아이콘 정렬이 다른 메뉴 항목과 맞춰졌습니다.

### 알려진 제약

- Dock 메뉴는 Tauri 가 지원하지 않아 메뉴바의 File > Open Recent 로 대체했습니다.
- 알림을 클릭해 해당 프로젝트로 바로 이동하는 기능은 사용 중인 알림 플러그인이 지원하지 않아 넣지 못했습니다.
- pi 에이전트 감지·훅은 CLI 가 설치되지 않은 환경에서 공식 문서 기준으로 구현했습니다. gemini 는 기존 방식을 유지했으며, 두 CLI 모두 이 환경에서 실제 동작은 확인되지 않았습니다.
- codex 의 새 훅 전달 방식이 실제로 작동하는지는 사용자 환경에서 추가 확인이 필요합니다.
- 새로 손질한 테마 색상의 실제 화면 검수(스크린샷 비교)는 아직 진행되지 않았습니다.
- 같은 프로젝트를 여러 분할 영역에 동시에 열 수 없습니다. 그룹을 열 때 분할 영역에 자동으로 배치되지는 않습니다(사이드바에 순서대로 열릴 뿐입니다). 키보드만으로 화면을 분할하는 기능은 없습니다(드래그 또는 컨텍스트 메뉴 필요).
- 탐색기에서 Enter 키의 동작이 이전 버전과 달라졌습니다(이름 바꾸기로 변경). 폴더를 펼치거나 접으려면 화살표 키나 클릭을 사용하세요.

### 설치

1. `TAIDE_0.2.0_aarch64.dmg` 를 내려받아 열고 TAIDE 를 Applications 로 드래그합니다.
2. Developer ID 서명·Apple 공증이 완료된 빌드라 별도 허용 절차 없이 바로 실행됩니다.
3. 무결성 확인(선택): `shasum -a 256 -c SHA256SUMS.txt`

요구 사항: macOS (Apple Silicon)
