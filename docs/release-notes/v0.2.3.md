## TAIDE v0.2.3 — 탭·포커스 안정화 · 미저장 편집 보호 · 보조 창 정합 (macOS Apple Silicon)

편집 화면 전반을 다시 훑어 미저장 편집이 조용히 사라지던 경로를 여러 곳 막은 유지보수 릴리스입니다. 화면을 나눴을 때 포커스와 단축키가 엇나가던 문제, 새 패널을 열거나 닫을 때 편집 내용이 저장 안 되던 문제를 고쳤고, 탐색기·터미널·언어 서버·보조 창 전반의 자잘한 결함도 함께 정리했습니다.

### 에디터 · 탭

- 화면을 나눈 뒤 포커스된 쪽의 마지막 탭을 닫으면 그 다음부터 파일 트리 클릭·⌘P·저장·닫기가 전부 먹통이 되던 문제를 고쳤습니다. 이제 포커스는 남은 화면으로 자동으로 넘어갑니다.
- 에디터 본문·터미널·미리보기 등 어디를 클릭하든 그 화면이 포커스를 가져갑니다. 이전에는 탭 제목을 직접 눌러야만 포커스가 옮겨가, 화면을 나눈 뒤 기존 화면 본문을 클릭해 편집해도 저장·닫기 단축키가 새로 연 화면을 겨냥했습니다.
- 미리보기 탭을 편집하거나 고정하면 일반 탭으로 바뀝니다. 이전에는 편집 중이던 미리보기 탭이 다음 파일을 단일 클릭으로 열 때 확인 없이 그 자리에서 교체돼 사라졌고, 고정한 미리보기 탭도 같은 식으로 덮였습니다.
- 고정 탭은 드래그·되살리기(⌘⇧T)·보조 창에서 돌아오는 경우 전부 고정 구역 안에 머뭅니다. 이전에는 특정 경로에서 고정 구역을 벗어나 탭 순환·"오른쪽 탭 닫기"가 화면과 다른 탭을 잡았습니다.
- 미저장 편집이 있는 탭을 닫으려 하면 저장 / 저장 안 함 / 취소를 묻는 확인창이 뜹니다. 여러 탭을 한 번에 닫을 때는 질문이 한 번만 뜨고 답이 전체에 적용됩니다. "저장"을 선택하면 실제로 디스크에 쓰인 뒤에만 탭이 닫히고, 읽기 전용 파일이거나 저장이 실패하면 닫히지 않습니다.
- 같은 파일을 두 번째 화면에 열어도 첫 번째 화면의 편집 내용이 사라지지 않습니다. 이전에는 편집 중이던 내용이 디스크 내용으로 덮이거나, 반대로 편집한 적 없는 화면에 "미저장 내용을 복구했습니다" 배너가 잘못 뜨며 편집이 롤백되는 경우가 있었습니다.
- 검색 결과·진단·정의로 이동할 때 화면이 나뉜 상태에서도 방금 연 탭이 있는 쪽 화면이 그 줄로 이동합니다. 이전에는 같은 파일이 다른 화면에 이미 열려 있으면 그쪽이 대신 반응하고 정작 새 탭은 첫 줄에 머물렀습니다.
- "저장 안 함"으로 닫은 탭을 되살리기(⌘⇧T)로 다시 열면 더 이상 미저장 표시가 남아 있지 않습니다.
- 탭 여러 개를 한 번에 닫는 도중 하나가 이미 사라져 실패해도 나머지는 계속 닫히고, 그 외 진짜 실패만 알림으로 표시합니다.
- 이름 없는(untitled) 탭에서 ⌘S를 누르면 저장 위치를 묻는 다이얼로그가 뜹니다. 이전에는 아무 반응이 없었습니다.

### 보조 창

- 보조 창에서 연 ⌘P의 심볼·라인 이동과 아웃라인 패널이 그 창에 떠 있는 파일을 정확히 대상으로 합니다. 이전에는 메인 창의 파일을 보고 있었습니다.
- 보조 창 탐색기에서 "터미널에서 열기"를 실행하면 지정한 폴더에서 셸이 열립니다. 이전에는 항상 프로젝트 루트에서 열렸습니다.
- 폰트 크기 단축키(⌘=, ⌘−)가 보조 창에서도 동작하고, 메인 창에서는 한 번 눌렀을 때 한 단계만 바뀝니다.
- 보조 창을 닫아도 그 안에서 편집하던 내용이 메인 창으로 돌아온 탭에 그대로 남습니다. 창을 연 직후 빠르게 닫아도 유령 미저장 표시가 남지 않습니다.
- 같은 파일이 메인 창과 보조 창에 동시에 열려 있는 상태에서 보조 창을 닫으면 탭이 하나로 합쳐지고 미저장 상태는 유지됩니다. 보조 창에서 고정해 둔 탭도 고정 상태를 유지한 채 돌아옵니다.
- 터미널 탭을 다른 창으로 옮기면 셸이 새로 스폰되지 않고 기존 세션에 그대로 이어집니다.

### 탐색기 · 검색

- 폴더를 삭제한 뒤 곧바로 "새 파일"을 만들면 삭제된 폴더가 아니라 프로젝트 루트에 만들어집니다. 이전에는 사라진 선택 상태가 남아 있어 삭제된 폴더가 되살아났습니다.
- "옆에 열기"는 이제 항상 화면을 실제로 나눕니다. 이전에는 특정 상황에서 파일만 열리고 분할이 되지 않았습니다.
- 보조 창의 탐색기 자동 추적(파일을 열면 트리에서 자동으로 펼쳐 보여주는 기능)이 그 창에 열린 파일을 따라가고, 메인 창 사이드바를 접어도 계속 동작합니다.
- 디렉터리 심링크(예: 패키지 매니저가 만드는 링크 폴더)가 폴더로 표시되고 펼칠 수 있습니다. 이전에는 파일처럼 표시돼 열리지도 펼쳐지지도 않았습니다. 연결이 끊긴 심링크는 여전히 파일로 표시됩니다.
- 대량의 파일 변경으로 변경 감시가 따라잡지 못했다가 복구되면, 이미 펼쳐 둔 디렉터리 목록도 자동으로 최신 상태로 갱신됩니다.
- 무시된 디렉터리(예: 의존성 폴더) 안에서 "폴더에서 찾기"를 실행하면 그 안의 결과도 정상적으로 나옵니다. 이전에는 결과가 항상 0건이었습니다.
- "모두 접기"를 실행하면 화면에 보이지 않던 하위 디렉터리의 펼침 상태까지 함께 접힙니다.

### 터미널

- 새 터미널을 연속으로 열면 이제 탭이 두 개 생깁니다. 이전에는 하나만 열리고 두 번째 시도는 무시됐습니다.
- 작업 실행(Run Task) 시 현재 보고 있는 터미널로 명령이 들어갑니다. 이전에는 항상 첫 번째 터미널로 들어갔습니다.
- 터미널 전환 단축키(⌃\`)를 쓸 때 터미널 탭끼리는 서로 건너뛰지 않습니다.
- 셸 스폰에 실패한 터미널 탭에 재시작 버튼이 생겼습니다. 이전에는 복구할 방법이 없었습니다.
- 설정에서 늘린 스크롤백 줄 수가 실제로 반영됩니다. 이전에는 큰 값을 설정해도 일정 크기에서 잘렸습니다. 이번 변경은 새로 여는 터미널부터 적용됩니다.

### 프로젝트 · 세션

- 화면을 여러 프로젝트 슬롯으로 나눈 상태에서 포커스된 슬롯을 닫으면 포커스가 항상 첫 번째 슬롯이 아니라 바로 옆 슬롯으로 넘어갑니다.
- 슬롯 헤더의 닫기 버튼을 누를 때 그 슬롯으로 포커스가 먼저 옮겨가지 않습니다.
- 폴더가 사라진 프로젝트는 슬롯 헤더에 경고 배지가 뜨고, 사이드바 아이콘이 흐리게 표시되며, 탐색기에 안내와 함께 "다시 열기" 버튼이 나타납니다.
- "최근 항목 지우기"를 실행해도 미저장 초안이 남아 있는 프로젝트는 목록에서 지워지지 않고, 초안 때문에 보존됐다는 안내가 뜹니다.
- 프로젝트를 닫는 순간에도 직전 편집 내용이 안전하게 저장된 뒤 닫힙니다.
- 편집 중이던 파일이 외부에서 삭제되면 오류 화면 대신 "원본이 삭제됨" 안내와 함께 편집한 내용을 그대로 보여주고, 다른 이름으로 저장할 수 있습니다. 그 탭을 닫아도 이 내용은 지워지지 않습니다.

### 언어 서버

- 화면을 나눠 같은 파일을 두 곳에 띄워도 언어 서버로 보내는 변경 알림이 중복 전송되지 않습니다. 이전에는 한 글자 입력이 두 번 전송돼 존재하지 않는 오류 표시가 뜰 수 있었습니다.
- 이름 바꾸기 등으로 다른 열린 파일이 자동으로 수정되면, 화면에 띄운 적 없는 탭이라도 즉시 미저장 표시가 뜹니다.
- 언어 서버가 반복적으로 크래시해 재시도가 모두 소진돼도 구문 검사 등 기본 기능이 영구히 멈추지 않고 복구됩니다.

### 동작 변경 안내

- "옆에 열기"는 이제 항상 화면을 분할합니다. 이미 열려 있는 파일이면 같은 파일의 탭이 하나 더 생깁니다.
- 미리보기 탭은 편집을 시작하거나 고정하는 순간 일반 탭으로 바뀝니다.
- 미저장 편집이 있는 탭을 닫을 때 확인 다이얼로그가 새로 뜹니다.
- 터미널 스크롤백 설정은 이미 열려 있는 터미널에는 적용되지 않고, 다음에 새로 여는 터미널부터 적용됩니다.

### 알려진 제약

- 보조 창에만 열려 있는 파일에 대해 Claude Code 같은 외부 도구가 저장을 요청하면 아직 실제로 저장되지 않고 실패로 처리됩니다(이전에는 저장된 것처럼 잘못된 성공 응답을 보냈습니다).
- 터미널 탭을 닫을 때 그 안에서 실행 중인 프로세스가 있어도 확인 없이 즉시 닫힙니다.

### 설치

1. `TAIDE_0.2.3_aarch64.dmg` 를 내려받아 열고 TAIDE 를 Applications 로 드래그합니다.
2. Developer ID 서명·Apple 공증이 완료된 빌드라 별도 허용 절차 없이 바로 실행됩니다.
3. 무결성 확인(선택): `shasum -a 256 -c SHA256SUMS.txt`

요구 사항: macOS (Apple Silicon)
