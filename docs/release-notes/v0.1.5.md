## TAIDE v0.1.5 — 파일트리 git 상태·터미널 Shift+Enter·SCM 키보드 (macOS Apple Silicon)

일상 사용성 릴리스입니다. 탐색기 git 데코레이션, 내장 터미널의 Claude Code Shift+Enter 줄바꿈,
git 패널 키보드 내비게이션이 담겼습니다. (버전 정책상 0.1.4 는 건너뜁니다)

### 새 기능

- **파일트리 git 상태 표시 (VS Code 스타일)**: 변경된 파일이 탐색기에서 상태 색과 문자
  뱃지(M/A/D/R/U/!)로 표시됩니다. 변경을 품은 폴더는 색과 점 뱃지로 전파 표시되며, 스테이징·
  커밋 등 상태 변화에 실시간으로 따라갑니다.
- **터미널 Shift+Enter 줄바꿈**: 내장 터미널에서 Claude Code 등 TUI 를 쓸 때 Shift+Enter 가
  제출 대신 줄바꿈으로 동작합니다. 일반 셸 프롬프트의 동작은 그대로입니다.
- **git 패널 키보드 내비게이션**: 변경 파일 목록을 ↑↓ 로 이동하고 Enter/Space 로 diff 를 열 수
  있습니다. 포커스된 행은 배경으로 강조됩니다.

### 설치

1. `TAIDE_0.1.5_aarch64.dmg` 를 내려받아 열고 TAIDE 를 Applications 로 드래그합니다.
2. Developer ID 서명·Apple 공증이 완료된 빌드라 별도 허용 절차 없이 바로 실행됩니다.
3. 무결성 확인(선택): `shasum -a 256 -c SHA256SUMS.txt`

요구 사항: macOS (Apple Silicon)
