## TAIDE v0.1.2 — 첫 공개 릴리스 (macOS Apple Silicon)

TAIDE 는 터미널 에이전트(Claude Code 등)와의 협업을 중심에 둔 데스크톱 IDE 입니다.
Rust 코어가 상태를 소유하고 화면은 표시만 담당하는 구조로, 에이전트가 파일을 바꾸는 동안에도
에디터·git·트리가 항상 실제 디스크 상태를 따라갑니다.

### 주요 기능

- 에디터: Monaco + TextMate(shiki) 문법 하이라이팅, LSP 자동 감지·설치(5개 언어 내장,
  자동완성·정의 이동·진단·포매팅 등 어댑터 20종), 인라인 blame·diff·충돌 해석
- 터미널: 세션 유지·복원, 에이전트 감지(터미널 탭 아이콘·상태 표시), 작업 러너
  (package.json scripts·Makefile·Cargo.toml)
- Git: 상태·스테이징(훙크/라인 단위)·커밋 그래프·브랜치·stash·파일 히스토리, 외부(에이전트)
  변경의 실시간 반영
- AI: 자동완성·Inline Edit·커밋 메시지 생성 (Codex·Ollama Cloud·OMLX)
- 에이전트 연동: `taide` CLI(ctrl+g 왕복), IDE MCP 서버(Claude Code 자동 연결)
- 원격 접속: 브라우저에서 비밀번호 인증으로 프로젝트 접근(허용 호스트 화이트리스트)
- 커스터마이즈: 번들 테마 38종 + 테마 편집기·VSIX 테마/문법 임포트, 키맵 편집기, 3개 언어
  UI(한국어·영어·일본어), 멀티 윈도우·Zen 모드

### 이번 버전의 수정 (v0.1.0~v0.1.1 대비)

- 설치본에서 LSP 서버를 감지하지 못하던 문제 수정 (GUI 앱의 최소 PATH 보정)
- 설치본에서 문법 색상이 사라지고 호버가 어긋나던 문제 수정 (CSP 가 에디터 런타임 스타일을
  차단하던 근본 원인 해소)
- 개발 환경과 설치본의 데이터 완전 분리 (identifier `net.gumyo.taide` 로 개명 포함)
- 오류가 파일 로그(`~/Library/Logs/net.gumyo.taide/TAIDE.log`)에 남도록 진단 가시성 개선

### 설치

1. `TAIDE_0.1.2_aarch64.dmg` 를 내려받아 열고 TAIDE 를 Applications 로 드래그합니다.
2. Developer ID 서명·Apple 공증이 완료된 빌드라 별도 허용 절차 없이 바로 실행됩니다.
3. 무결성 확인(선택): `shasum -a 256 -c SHA256SUMS.txt`

요구 사항: macOS (Apple Silicon)
