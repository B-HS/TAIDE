# 병합 게이트가 실제 휴지통을 쓰는 검사를 실행함

## 무엇이 일어났나

2026-11-03에 메인이 만든 `docs/utils/2026-11-03-native-merge-gate.sh`가 앱 crate 전체 테스트를 `--skip` 없이 실행했습니다. 그 안에 실제 macOS 휴지통으로 파일을 옮기는 검사 3개가 들어 있었습니다. 이 스크립트로 게이트를 세 번 돌렸고, git lane 병합 작업자도 앱 lib 전체를 한 번 실행했습니다. 사용자 휴지통에 `delete-synthetic.txt` 같은 합성 테스트 파일이 들어갔을 수 있습니다. 휴지통 자체는 열거나 비우지 않았습니다. 인수인계 문서 작성자가 2026-11-04에 발견해 보고했습니다.

## 왜 틀렸나

- 2026-10-10 배치 게이트는 이 3개를 `--skip`으로 뺐는데, 스크립트를 새로 만들 때 그 기록을 확인하지 않았습니다.
- 작업자 지시에는 `tests/explorer-delete.rs` 실행 금지만 적었고, 같은 성격의 lib 검사(`remote_files::tests::실제_파일14명령과_raw는…`)와 `tests/lsp-workspace-worker.rs` 검사는 목록에 없었습니다.

## 어떻게 고치나

- 스크립트에 `TRASH_TESTS` 배열로 세 검사를 `--skip`합니다(커밋 `34fb88d7`).
- 필터 없는 앱 테스트는 이 스크립트로만 실행합니다. 작업자 지시의 금지 목록에는 세 검사 이름을 모두 적습니다(`docs/handoff/native-completion/00-README.md` 1절).

## 언제 적용하나

- 앱 crate 테스트를 필터 없이 실행하는 모든 게이트·작업자 지시에 적용합니다.
- 새로 실제 OS 자원(휴지통, 클립보드, Keychain, 알림)을 쓰는 검사가 생기면 같은 목록에 추가합니다.
