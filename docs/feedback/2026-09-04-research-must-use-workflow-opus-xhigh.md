# 리서치를 Explore 서브에이전트로 보낸 재위반 + 단계별 모델 배정 갱신 (2026-09-04)

## 무엇을 지적받았나

버그 3건(퀵오픈 파일 미발견·터미널 링크 창내 열림·파일트리 자동 reveal) 조사를 Agent 도구의
Explore 서브에이전트 3개로 병렬 위임했다. 사용자: "지금 돌아가는건 어쩔수없다 치고 이후 리서치
이런것들도 opus + xhigh workflow를 사용하도록해 sub agent는 사용금지야."

같은 메시지에서 단계별 역할 계약도 갱신됐다.

| 단계 | 도구 | 모델 · effort |
|------|------|---------------|
| 리서치 · 조사 | Workflow | opus · xhigh |
| 구현(코드 수정) — 메인이 명확한 지시·구현 방법을 먼저 작성 | Workflow | opus · xhigh |
| 구현 리뷰 | Workflow | sonnet · xhigh |
| e2e · 테스트 코드 생성 | Workflow | fable · medium |

## 왜 틀렸나

- `feedback/2026-08-11-use-workflow-not-agent-tool.md` 가 이미 "서브에이전트 위임은 규모와 무관하게
  Workflow 로" 라고 못 박았는데, "읽기 전용 조사는 구현이 아니니 Explore 로 충분하다"고 임의로
  예외를 만들었다. 합의된 예외 목록에 리서치는 없다.
- Agent 도구는 model/effort 를 계약대로 고정할 수 없고, 진행 상황·결과가 Workflow 진행 트리
  한 곳에 모이지 않는다.

## 어떻게 고치나

- 조사·원인 분석·설계 비교 같은 리서치도 **Workflow + opus·xhigh** 로 돌린다. 독립 주제는 한
  워크플로 안에서 `parallel`/`pipeline` 으로 병렬화한다.
- 메인이 직접 하는 것은 단순 파일 읽기·grep·문서 갱신·검증 실행에 한정한다.
- 이번 세션은 이미 돌던 Explore 3개는 결과를 소비하되, 이후 단계(구현·리뷰·테스트)는 위 표대로
  Workflow 로만 진행한다.

## 언제 적용하나

- 이 레포에서 서브에이전트에게 일을 맡기는 모든 경우. 리서치 포함, 항상.
- 세션 시작 시 HANDOFF 의 역할 계약과 이 표가 다르면 이 표(최신)를 따르고 HANDOFF 를 갱신한다.
