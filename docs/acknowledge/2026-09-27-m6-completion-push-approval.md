# M6 완료 범위와 원격 push 승인

상태: 사용자 명시 승인 완료.

## 범위

사용자는 활성 목표를 남아 있는 M6 전체를 마무리한 뒤 commit·push하는 것으로 변경했습니다. M7·M8 구현은 현재 목표에서 제외합니다. M6 완료 조건은 기존 roadmap과 실제 파일의 runtime·platform·Tauri adapter 분리 계약을 그대로 적용하며 일부 변경 단위의 완료로 전체를 완료 처리하지 않습니다.

## Git 승인

기존 원격 push는 목적지·전송 범위 승인 부족으로 거절되었습니다. 이후 사용자에게 검증된 M6 변경과 기존 미푸시 커밋을 GitHub `B-HS/TAIDE`의 `to_rust_native` 브랜치로 일반 push해도 되는지 한 번에 확인했고, 사용자는 해당 저장소·브랜치에 일반 push를 승인했습니다.

이 승인은 M6 전체 완료 후 해당 저장소·브랜치로 일반 push하는 것에 한정됩니다. force push·이력 재작성·다른 브랜치·다른 저장소·릴리스·앱 실행·시크릿 접근은 승인하지 않습니다. 관련 검증이 완료된 독립 변경 단위의 로컬 commit은 기존 규칙대로 계속 수행합니다.

## 실행 방식

메인이 직접 수행하고 서브에이전트는 사용하지 않습니다. 현 세션 모델을 유지합니다. M6 종료 결과와 실제 commit·push 명령 결과를 구분해 기록합니다.
