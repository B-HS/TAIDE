# 릴리스 태그 숫자 4 절대 금지 (2026-08-28, 사용자 지시)

## 결정 — 절대 규칙

- **릴리스 태그(`v*`)에 숫자 `4` 를 절대 포함하지 않는다.** 자리 무관 — major·minor·patch
  어디든 `4` 가 들어가는 태그는 금지다 (예: `v0.4.0`·`v1.4.2`·`v0.1.4`·`v4.0.0` 전부 불가).
- 태그는 `tauri.conf.json` version 과 일치해야 하므로(release.yml 가드), **앱 버전 자체도
  4 를 포함하는 버전을 건너뛴다**: `0.3.x` 다음은 `0.5.0`, `x.y.3` 다음 patch 는 `x.y.5`.
- 이 규칙은 향후 모든 릴리스·버전 결정에 무조건 적용한다. 재론 금지.

## 강제 장치

- `.github/workflows/release.yml` 의 "Verify tag contains no digit 4" 스텝이 태그에 `4` 가
  포함되면 릴리스를 즉시 실패시킨다 (버전 일치 가드보다 먼저 실행).
- 버전 산정 시(로컬에서 태그를 만들 때)도 이 문서를 우선 확인한다 — CI 실패 전에 사람이
  먼저 거른다.
