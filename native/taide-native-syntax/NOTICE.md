# taide-native-syntax third-party notices

This crate contains material that belongs to other projects. The repository
root `THIRD_PARTY_LICENSES.md` is the authoritative notice; this file maps
each piece of this crate to it.

## TextMate grammars

- Files: `grammars/*.tmLanguage.json` (37 files) and `grammars/manifest.json`.
- Origin: `@shikijs/langs` 4.4.3. Each grammar file is the value of the JSON
  string literal embedded in `node_modules/@shikijs/langs/dist/<id>.mjs`,
  written out as is (never parsed and re-serialized) by
  `docs/utils/2026-10-06-extract-shiki-grammars.ts`. `manifest.json` is
  metadata generated by the same script (ids, scope names, imports, SHA-256).
- The grammar files must not be edited or re-serialized. Regenerate them with
  the script instead.
- License: the `@shikijs/langs` package is MIT (`LICENSE-SHIKI`). Each grammar
  keeps its upstream license; see "Bundled TextMate Grammars" in
  `THIRD_PARTY_LICENSES.md`.

## Ported source

- `src/style-scopes.rs` ports the color and font style lookup of
  `@shikijs/monaco` 4.4.3 (`dist/index.mjs`: `normalizeColor`,
  `normalizeFontStyleString`, `normalizeFontStyleBits`, `getColorStyleKey`,
  and the rule table built in `textmateThemeToMonacoTheme` and `setTheme`).
  License: MIT (`LICENSE-SHIKI`).
- `src/style-scopes.rs` ports `toStandardTokenType` from Monaco Editor 0.56.0
  (`esm/vs/editor/common/languages/supports/tokenization.js`). License: MIT
  (`LICENSE-MONACO-SNIPPET`).
- `src/monaco-token-theme.rs` ports the token theme of Monaco Editor 0.56.0
  (`esm/vs/editor/common/languages/supports/tokenization.js`:
  `parseTokenTheme`, `resolveParsedTokenThemeRules`, `ColorMap`,
  `ThemeTrieElement`, `ThemeTrieElementRule`). License: MIT
  (`LICENSE-MONACO-SNIPPET`).
- `src/token-theme.rs` ports `normalizeTheme` from `@shikijs/primitive` 4.4.3
  (`dist/index.mjs`) and the rule list built by `textmateThemeToMonacoTheme`
  in `@shikijs/monaco` 4.4.3. License: MIT (`LICENSE-SHIKI`). It also ports
  the default rule that `StandaloneTheme.tokenTheme` adds in Monaco Editor
  0.56.0 (`esm/vs/editor/standalone/browser/standaloneThemeService.js`).
  License: MIT (`LICENSE-MONACO-SNIPPET`). The theme assembly in the same
  file follows TAIDE's own `src/shared/lib/shiki/build-shiki-theme.ts`.
- `src/document-tokens.rs` and `src/token-worker.rs` port the line end state
  store and the stop rule of Monaco Editor 0.56.0
  (`esm/vs/editor/common/model/textModelTokens.js`: `TokenizationStateStore`,
  `TrackingTokenizationStateStore`) and the document size limits of
  `esm/vs/editor/common/model/textModel.js`. License: MIT
  (`LICENSE-MONACO-SNIPPET`).

## Test fixtures

- `tests/fixtures/samples/*.sample` are synthetic and written for this crate.
- `tests/fixtures/reference/**` is generated from those samples by
  `docs/utils/2026-10-06-generate-syntax-reference.ts`. The `settings` array
  in each `theme.json` is derived from the bundled themes
  `crates/taide-theme/resources/themes/{one-dark-pro,github-light}.json`,
  which are covered by "Bundled Themes" in `THIRD_PARTY_LICENSES.md`.
- `tests/fixtures/token-themes/synthetic/*.json` are synthetic and written for
  this crate.
- `tests/fixtures/token-themes/reference/**` is generated by the same script
  run with `--token-themes`. The `settings` array in each
  `reference/bundled/<id>.json` is derived from the bundled theme
  `crates/taide-theme/resources/themes/<id>.json`, which is covered by
  "Bundled Themes" in `THIRD_PARTY_LICENSES.md`.
