## TextMate grammars

- Files: `grammars/*.tmLanguage.json` (37 files) and `grammars/manifest.json`.
- Origin: `@shikijs/langs` 4.4.3. Each grammar file is the value of the JSON
  string literal embedded in `node_modules/@shikijs/langs/dist/<id>.mjs`,
  written out as is (never parsed and re-serialized) by
  `docs/utils/2026-10-06-extract-shiki-grammars.ts`. `manifest.json` is
  metadata generated by the same script (ids, scope names, imports, SHA-256).
- The grammar files must not be edited or re-serialized. Regenerate them with
  the script instead.
- License: the `@shikijs/langs` package is MIT (`LICENSE-SHIKI`). Each grammar
  keeps its upstream license; see "Bundled TextMate Grammars" in
  `THIRD_PARTY_LICENSES.md`.

## Monaco language configurations

- Files: `language-configurations/monaco.json` and
  `tests/fixtures/language-configurations/reference.json`.
- Origin: `monaco-editor` 0.56.0. `monaco.json` holds the `conf` object of
  each language definition TAIDE's language ids use
  (`esm/vs/languages/definitions/<language>/<language>.js`), the
  `richEditConfiguration` of `esm/vs/languages/features/json/jsonMode.js` and
  the plain text configuration registered by
  `esm/vs/editor/common/languages/languageConfigurationRegistry.js`. Regular
  expressions are stored as their unchanged `source` and `flags`.
  `reference.json` records what Monaco's own classes return for those
  configurations on the synthetic sample lines.
- Both files are generated by
  `docs/utils/2026-10-07-extract-monaco-language-configurations.ts` and must
  not be edited by hand.
- License: MIT, Copyright (c) Microsoft Corporation
  (`LICENSE-MONACO-SNIPPET`).

  `reference/bundled/<id>.json` is derived from the bundled theme
  `crates/taide-theme/resources/themes/<id>.json`, which is covered by
  "Bundled Themes" in `THIRD_PARTY_LICENSES.md`.
